Where each control acts

Read top to bottom: a request starts with someone asking and ends at the data. Every SC-500 security-for-AI bullet sits on one layer.

Who askspeople and agents

A person in Microsoft 365 Copilot

Copilot answers with the signed-in user's own permissions, through Microsoft Graph. No privileged index.

Copilot Studio agent

Built by any licensed maker. Generative orchestration plans which tool to call next.

Foundry agent or app

Calls a model deployment, and for agents, tools such as search, functions and APIs.

Identitywho the agent is

Runtimewhat it is allowed to do now

Copilot Studio real-time protection (preview)3.1.3

Defender checks each tool call before it runs. In the new rules experience the Default rule only audits; a custom rule blocks. Generative orchestration only.

AI gateway in API Management3.1.7

One chokepoint in front of models: token limits per consumer, content safety, the model key kept off the apps.

Foundry guardrails3.1.9

Controls on user input, output, and for agents (preview) tool calls and tool responses. Annotate, or annotate and block.

Datawhat it can read

SharePoint oversharing3.1.1

Data access governance reports find it. Restricted Content Discovery hides a site from Copilot; Restricted Access Control removes access.

Purview DSPM (was DSPM for AI)3.1.2

Who used which AI app with what data. Labels with encryption: Copilot needs VIEW and EXTRACT to summarise.

Detectionwho notices

Defender for AI Services3.1.8

Runtime threat detection on prompts and responses: jailbreaks, data leakage, credential theft. Alerts; never blocks.

Defender CSPM3.1.10

Discovers AI resources, builds the AI bill of materials, finds AI attack paths. Posture, not runtime alerts.

One indirect prompt injection, five places to stop it

An attacker never touches the agent. They plant instructions in content it will read, and let its own access do the rest.

Instructions planted in a document3.1.13.1.2

A file the agent grounds on contains hidden instructions, often in a site shared far too widely.

Stop it: Fix the oversharing; RCD or RAC while you review; labels without EXTRACT.

The agent reads it3.1.9

Grounding or a tool returns the poisoned text into the agent's context.

Stop it: A guardrail with indirect attack detection on the tool response.

The agent plans an action3.1.33.1.9

It decides to send an email or call an API with data it holds.

Stop it: A real-time protection custom rule blocks the tool call; a tool call control in Foundry.

The action runs with the agent's access3.1.43.1.6

Whatever the agent identity, or the delegated user, can reach is in play.

Stop it: Least privilege, expiring access, Conditional Access for unapproved agents.

Someone notices3.1.53.1.8

The SOC needs the alert, the prompt and the reach.

Stop it: Defender alerts with prompt evidence; blast radius; DSPM activity.

Copilot Studio real-time protection (preview)3.1.3

Agent plans a tool call→Defender evaluateswithin about 1 s→Audit or blockthe rule decides
  • Two sides, both required. Defender portal: Settings, Security for AI, Get started, Copilot Studio step, real-time protection on. Power Platform admin center: Security, Threat detection, per environment.
  • New rules experience (Agent 365): the built-in Default rule audits every agent; to block, create a custom rule under Settings, Security for AI, Policies & rules, Real-time protection. The legacy Defender for Cloud Apps path stays unchanged for tenants that keep it.
  • Only generative orchestration agents. Classic agents are skipped.
  • No answer in time: the default is allow; you can change it to block.
  • Blocks are recorded as behaviours. When a blocking rule covers an agent, near-real-time alerts are not generated.
  • Evidence it works: the Copilot Studio step shows Connected.

Foundry guardrails3.1.9

Intervention pointModelsAgents (preview)
User inputYesYes
Tool callNoYes, tools that support it
Tool responseNoYes, tools that support it

  • A guardrail is a set of controls: risk + intervention point + action (annotate, or annotate and block; agents only annotate and block).
  • An agent's own guardrail replaces the model's entirely. No agent guardrail: it inherits the model deployment's.
  • Default Microsoft.DefaultV2 cannot be edited. Azure OpenAI default: harm categories at Medium, jailbreak on prompts, protected material on completions. No indirect attack detection by default.
  • Groundedness and Spotlighting apply to models only. Blocklists: up to 10,000 terms, Azure OpenAI only.

Agent ID access and the agent registry3.1.53.1.63.1.11

  • owner: blueprint and agent identity. sponsor: blueprint, agent identity, agent user. manager: agent user.
  • Access packages give agents access that expires unless the sponsor asks to extend it.
  • Sponsorship lifecycle workflows move sponsorship when a sponsor leaves.
  • Microsoft 365 admin center, Agents, All agents: install, block, delete and restore (30 days), assign a new owner, start or stop a Foundry agent.
  • Blast radius: Defender incident graph, View blast radius. Needs Exposure Management read and Sentinel data lake onboarding before 23 September 2026 (legacy incident experience); it only reaches assets classified as critical.

Oversharing and DSPM for AI3.1.13.1.2

ControlChanges access?
Restricted Content DiscoveryNo. Hides the site from Copilot and org-wide search
Restricted Access ControlYes. Only the named groups can open the site
Label with encryption, no EXTRACTNo. The user opens it; Copilot cannot summarise it
DLP for Microsoft 365 CopilotStops Copilot processing labelled content
  • Microsoft 365 Copilot prompts and responses live in the user's mailbox: eDiscovery or the AI interaction event in activity explorer.
  • Copilot in Fabric, Security Copilot and third-party apps need a collection policy, with content capture where needed.
  • DSPM for AI is now DSPM for AI (classic). The new DSPM (Purview portal, Solutions, DSPM) replaces it and adds AI observability for apps and agents.
  • Reports need at least a day to fill. RCD can take more than a week on very large sites.

SharePoint controls that shrink what Copilot can find3.1.1

  • Default sharing links set to Specific people, not the whole organisation.
  • Hide the Everyone except external users claim from the sharing picker.
  • Restrict member sharing on sensitive sites, so owners handle access requests.
  • Site access reviews from a data access governance report: the site owner decides what was oversharing.
  • Inactive site policies: every abandoned site is more content Copilot reasons over.
  • Hiding is not fixing: RCD buys time, permissions are the fix.

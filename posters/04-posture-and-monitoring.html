Regulatory compliance4.1.21.3.2

Standardan Azure Policy initiative→Controls→Recommendations→Your resources
  • The benchmark is assigned by default. Other standards need any paid plan except Servers Plan 1 or APIs Plan 1.
  • Adding a standard: Microsoft's pages name different roles (Policy Contributor; Resource Policy Contributor plus Security Admin). Owner satisfies both.
  • Accepted risk: a waiver exemption (expiry optional), not removing the resource from scope.
  • The dashboard shows how your resources score against a framework. It is not an audit report.

DevOps security1.3.94.1.1

  • Connect Azure DevOps, GitHub or GitLab in Environment settings.
  • Microsoft Security DevOps runs scanners, including infrastructure-as-code checks, in the pipeline.
  • Pull request annotations and code-to-cloud mapping need Defender CSPM.
  • DevOps recommendations do not affect the secure score.
  • A Deny policy still stops a non-compliant template at deployment, whichever tool sends it.

Anatomy of an attack path4.1.1

Internet exposureopen port, public IP→Vulnerable machinecritical CVE→Its identitymanaged identity→Its permissionsrole on a storage account→Sensitive data
  • Each box alone is one recommendation among thousands. The chain is one prioritised finding.
  • Cloud security explorer queries the same graph directly: "internet-facing VMs with a critical vulnerability and access to sensitive data" is one query.
  • The graph is fed by agentless scanning, Defender Vulnerability Management, container image scanning, secret scanning and data classification. Missing inputs mean missing paths.

Multicloud, vulnerabilities and attack surface4.1.44.1.54.1.6

  • AWS and GCP: security connectors in Environment settings. Azure Arc auto-provisioning gives their machines the full Defender for Servers feature set; decline it and agentless scanning still covers them, but Arc-dependent features do not.
  • Defender Vulnerability Management for Azure VMs: through the Defender for Endpoint extension (on by default with a Servers plan) or agentless disk scanning. CMK-encrypted disks need Key Vault permissions first.
  • Defender EASM looks from the outside, from seeds: domains, IP blocks, ASNs. Its own Azure resource and bill: 30-day trial, then billed per asset in Approved Inventory.

Sentinel in the Defender portal4.2.14.2.2

  • Onboarding sets a primary workspace; more workspaces can join. It needs Security Administrator in Entra ID, plus Owner (unconditional, at the subscription) or User Access Administrator with Microsoft Sentinel Contributor.
  • The Defender XDR connector turns on automatically when the workspace joins.
  • GDAP with Azure Lighthouse is not supported for Sentinel data in the Defender portal: use Entra B2B and Defender multitenant management. Lighthouse still lets advanced hunting query other tenants' workspaces with workspace().
  • Content hub installs need Microsoft Sentinel Contributor on the resource group.

Cost controls4.2.14.2.9

  • Set a daily cap before the first connector. When reached, collection stops: security data too.
  • Filter in the data collection rule: what the agent never collects is never billed (XPath for Windows events; facilities and severities for syslog). Transformation filtering is free only for Analytics tables in Sentinel workspaces.
  • Commitment tiers: raising one restarts its 31-day period; lowering waits until the period ends, except within 6 hours of a change.
  • Keep verbose tables short in the analytics tier and long in the data lake.

Microsoft Security Copilot4.3.14.3.24.3.34.3.4

CapacityBilling
Provisioned SCUs (1 to 100)Hourly, from the moment provisioned
Overage SCUsOnly when used
Microsoft 365 E5 or E7400 SCUs a month per 1,000 licences, up to 10,000; default capacity, not billed hourly
  • Each workspace has its own capacity, plugins and role assignments. SCUs are not shared between workspaces.
  • Provisioning needs Azure Owner or Contributor and Security Administrator.
  • Contributor defaults to the Recommended Microsoft Security roles group. Everyone is the legacy default; once removed it cannot be re-added.
  • Copilot answers with the user's own permissions. Plugins decide what it can reach; custom plugins are off for contributors by default.
  • Agents run with an agent identity (recommended; Microsoft-built agents only) or a user account, and consume SCUs as they work.
